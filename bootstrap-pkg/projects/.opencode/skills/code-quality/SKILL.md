# Code Quality Skill

When working on code quality:

1. **Linting**: Run appropriate linters (eslint, prettier, etc.)
2. **Type Checking**: Ensure TypeScript compiles without errors
3. **Formatting**: Apply consistent code formatting
4. **Dead Code**: Identify and remove unused code
5. **Complexity**: Refactor complex functions
6. **Documentation**: Add missing JSDoc comments
7. **Tests**: Ensure adequate test coverage

## Commands to Run
- `npm run lint` - Check for linting errors
- `npm run typecheck` - Verify TypeScript types
- `npm run format` - Format code with prettier
- `npm test` - Run test suite

## Quality Metrics
- Maintain >80% test coverage
- Keep function complexity low
- Follow SOLID principles
- Use meaningful names
